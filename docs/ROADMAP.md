## M1 — 移动系统垂直切片 🔄 当前阶段

**目标：** 玩家移动手感达到"好玩"的标准，所有核心移动动作可玩。

### 任务清单

#### 1.1 地面动作打磨
- [x] 待机 idle
- [x] 奔跑 run
- [x] 跳跃 airborne
- [x] 滑铲 slide
- [ ] 动作参数微调（加速度、摩擦、跳跃曲线）
- [ ]  coyote time / jump buffer 等手感优化

#### 1.2 墙面动作（核心层）
- [ ] 墙滑 wall_slide — 确定下落速度、控制感
- [ ] 墙跳 wall_jump — 确定跳跃角度、力度、输入缓冲
- [ ] 墙面动作与地面动作的切换逻辑

#### 1.3 墙面动作（扩展层，预留接口）
- [x] wall_climb 原型
- [x] wall_grab 原型
- [x] wall_kickout 原型
- [ ] 整理为可插拔的扩展状态，默认不启用

#### 1.4 移动动画同步
- [x] idle 动画
- [x] run/move 动画
- [x] airborne 动画
- [ ] wall_slide 动画
- [ ] wall_jump 动画
- [ ] 动画与代码同步调试

**M1 完成标准：** 在 playground 场景中，玩家可以流畅完成跑、跳、滑、墙滑、墙跳的连续操作，手感满意。

## M2 — 相机导演系统 + 动作衔接

**目标：** 镜头语言提升，动作过渡自然。

### 任务清单

#### 2.1 相机导演系统
- [ ] 相机基础跟随（非焊死，有缓动）
- [ ] 左右移动预测偏移
- [ ] 向上/向下移动预测偏移
- [ ] 坠落时相机下移
- [ ] 环境事件触发相机运动接口
- [ ] 相机边界/限制

#### 2.2 动作衔接动画
- [ ] 起跑过渡（idle → run）
- [ ] 落地过渡（airborne → idle/run）
- [ ] 起身过渡（slide → idle/run）
- [ ] 墙滑进入/离开过渡
- [ ] 统一过渡时长与缓动曲线

**M2 完成标准：** 角色动作无生硬切换，相机跟随自然且有预测感。

## M3 — 战斗系统原型

**目标：** 攻/防/闪三板斧可玩，伤害系统跑通。

### 任务清单

#### 3.1 训练场
- [ ] 训练场场景搭建
- [ ] 调试假人（可被攻击、显示伤害数字）
- [ ] 假人反击模式（0伤害，用于测试防御/闪避）

#### 3.2 玩家战斗基础
- [ ] 轻攻击（含动画）
- [ ] 重攻击（含动画）
- [ ] 防御（含完美防御/弹反判定）
- [ ] 闪避（含无敌帧）
- [ ] 战斗状态与移动状态的切换

#### 3.3 伤害计算系统
- [ ] 伤害公式
- [ ] 受击反馈（击退、硬直）
- [ ] 防御减伤/弹反机制
- [ ] 伤害数字 UI

#### 3.4 派生动作（初步）
- [ ] 轻攻击连段派生
- [ ] 闪避后攻击派生
- [ ] 防御反击派生

**M3 完成标准：** 在训练场中可完整演练攻击→防御→闪避→反击循环，伤害数字正确显示。
