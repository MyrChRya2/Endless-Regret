## R — 周期性任务（贯穿开发全程）

> 不属于任何单一里程碑，按固定节奏执行。当前仅一项。

### R1 每周开发日志自媒体视频 📹

**目标：** 每周 1 期，记录开发过程并积累受众，为游戏上线预热（与 CC0 开源 + 赞助链接定位匹配）。

**素材来源（复用现有产出）：**
- `docs/devlog/` 开发日志 → 视频大纲与文案底稿
- Godot 实机录屏（playground / 新功能演示）
- Aseprite 动画绘制过程录屏

**素材采集方式（2026-08-19 决策）：**
- **OBS 回放缓冲（Replay Buffer，60s）**：平时只缓冲不落盘，bug/亮点出现后按快捷键（Ctrl+Shift+F12）保存最近 60 秒——过程素材随手抓，不全程录屏
- **主动录制**：① 每个可玩功能完成时录 30s~1min 演示；② M1 完成时专门录全动作连招（= R1 首期主素材）；③ 正式素材用 Godot Movie Maker（`--write-movie`）逐帧导出
- 全程录屏不采用（磁盘/性能/无效内容成本高）

**标准流程：**
1. 周一：整理上周 `docs/devlog/` → 拟定本期主题与大纲
2. 周中：补录素材（实机 / 动画过程），撰写口播稿
3. 周末：剪辑成片 → 发布 → 记录数据（播放/互动）到 devlog 或内容工作区

**待决策：**

- [ ] 出镜与否（纯录屏解说 / 露脸）
