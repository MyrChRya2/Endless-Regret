- 结束点贴瓦片上表面（而非留余量下落）→ 位置精确、"正好在平台地面上"，无粘滞无两阶段

- 动画物理驱动 + 分段帧分配 → 动画与爬升运动同步（垂直动作/水平动作分别对应帧段），两常量可配置

## 补记：B4 乒乓修复（WallGrab ↔ Airborne）

> 用户实机报告 + 后台记录器抓取定位（辅助编程会话，特殊要求写日志）。

### Bug 描述
玩家贴 tile 43 右面（x≈712）下滑，约 l_ray_from y∈[-300,-260]（玩家 y∈[-259,-219]）时 WallGrab ↔ Airborne 反复切换（乒乓）。

### 排查过程
- **headless 直接复现失败**：把玩家精确放贴墙位置（间隙 0）→ 稳定；实机玩家从 Airborne 按向墙进入，停在接触 margin 边界
- **后台记录器**（	ools/b4_recorder.gd 挂 playground，逐帧 CSV）：实机日志显示乒乓期间 on_wall 逐帧 true/false 抖动，contact 在 FULL/NONE 间交替——Airborne(on_wall=true, FULL) → WallGrab(on_wall=false, NONE) → 循环
- **根因**：玩家从 Airborne 贴墙进入时，move_and_slide 的接触 margin（0.08px）让玩家停在墙面 0.08px 外；WallGrab 期间 elocity.x=0 不再向墙推 → is_on_wall 在判定边界抖动 → WallGrab（is_on_wall=false 退 Airborne）与 Airborne（贴墙 FULL 进 WallGrab）互相拉扯

### 修复
wall_grab.gd：elocity.x = 0 → 微小向墙速度 -sign(wall_normal.x) * 1.0——被墙面阻挡（无水平位移）但持续接触使 is_on_wall 稳定。

### 验证
- 	ools/test_b4.gd（margin 边界 x=712.08 进入）：修复前 12 次乒乓交替 → 修复后稳定 180 帧
- 用户实机确认：不再乒乓抖动
