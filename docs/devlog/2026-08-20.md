### B1 挂边判定误判修复（P0 重点）

**根因定位**（headless 自动扫描 + 定向复现，`tools/` 测试套件）

- **场景①（头顶有瓦片 → 误进 LedgeSlide/LedgeGrab）**：垂直平台顶射线偏移进墙体内部（表面内 2px）后，会命中**相邻瓦片之间的接缝边界**——接缝法线同样是 (0,-1) 的水平面，与真实墙顶无法区分。玩家沿墙下滑时，头顶每经过一个瓦片接缝就有约 8px 的误判窗口：WallGrab 中 `LEDGE_TOP → LedgeGrab` 错误转换，Airborne 中 `LEDGE_TOP → LedgeSlide` 错误进入。全图墙面扫描实测：墙列 0/75/98/113/120 均复现（修复前共 129 处标记）。
- **场景②（脱墙后不再回 WallGrab）**：`wall_escape` 脱离锁只在落地/跳跃时复位，WallGrab 脚底离墙进入 Airborne 后**整段下落都跳过贴墙检测**，再贴任何墙都不回 WallGrab。定向复现确认：锁置位时贴墙 300 帧不再抓墙，直接落地。

**修复**

- ① `is_head_touching_ledge()` 增加**空间判据**（与高度 + 法线组成三判据）：命中面正上方 2px 处用微型圆 `intersect_shape` 检测是否埋入碰撞体——接缝上方仍有瓦片（墙体延续）→ 拒绝；真实墙顶上方是空的 → 接受。
- ② 脱离锁自动复位：置位时记录 `wall_escape_time`（0.5s），`_physics_process` 中**完全离开墙面（is_on_wall=false）立即复位**，仍贴墙则超时兜底复位——覆盖"脱墙后落到下方/旁边墙面再贴"的路径。

**验证**（headless，`godot.windows.editor.x86_64.exe --headless --path Game_Build --script tools/xxx.gd`）

- `test_b1.gd`（全图墙面扫描）：修复前 129 处误判，修复后 0 处接缝误判；仅剩 -13 列 16 处为判定器误报（玩家滑过墙面底部后蹭到地板边缘的合法行为，修复前同样存在）

## 补记 6（同日追加）

### LedgeClimb 改为过程式（上爬插值）

**需求**：上爬从"瞬移式"（一帧跳到平台顶）改为"过程式"——有持续时长的爬升动作，为 ledge_climb 动画铺路。

**实现原理**：
- 进入后首帧做初始化检测（平台顶在头顶垂直射线范围内 + 头顶净空点采样），失败立即回退（头顶贴平台顶 → LedgeGrab，否则 → LedgeSlide），不启动过程
- 成功后记录 `_from_pos`（挂边位置）与 `_to_pos`（平台顶面上方，x 向平台内侧移 16px 站上台面）
- 每帧累计 `_elapsed`，`t = clamp(_elapsed / CLIMB_DURATION, 0, 1)`，位置 = `_from_pos.lerp(_to_pos, t)`（线性插值）
- 过程时长 `CLIMB_DURATION = 0.35s`（占位，动画帧确定后对齐）；过程内关重力、velocity=ZERO、不响应输入（锁定）
- `t >= 1` → 进 Idle，exit 恢复重力，当帧 move_and_slide 落定贴合平台顶

**验证**：`tools/test_climb.gd` 7 场景全过；序列显示 `LedgeGrab → LedgeClimb（21 帧）→ Idle`，确认过程式生效；失败回退仍为首帧立即回退（`LedgeClimb → LedgeGrab/LedgeSlide`）。

## 补记 7（同日追加）

### 空帧占位动画显示 error（开发期可视化）

**问题**：`_handle_anim()` 只对"动画名不存在"（`has_animation == false`）播放 error 占位；而 `ledge_*` / `slide` 已在 SpriteFrames 注册**空帧条目**（`frames: []`，2026-08-19 起的占位约定）——`has_animation` 返回 true → 正常"播放"0 帧动画 → 玩家隐身，缺失动画不可见。

**修复**：`_handle_anim` 判定改为 `has_animation(name) and get_frame_count(name) > 0`——空帧占位视为缺失 → 播放 error 占位（红色块，开发期可见）+ 一次性 `push_error` 警告；补帧后自动恢复正常播放。

**验证**：probe 确认 idle/wall_grab（有帧）正常、ledge_climb/ledge_grab（空帧）→ error 占位；`test_climb.gd` 7 场景回归全过（流程不受影响）。
