# EndlessRegret

2D 横版动作平台跳跃游戏。一个做错事之人的赎罪之路。

- 引擎：Godot 4.7
- 分辨率：640×360 像素
- 平台：Steam（计划免费/低价，CC0 开源）

## 当前阶段

**M1 — 移动系统垂直切片**

## 开发原则

- 一次只推进一个里程碑
- 动画与代码同步推进，不积压
- 移动系统未完成前不启动战斗开发
